About | Phan Tien Thinh

I'm Phan Tien Thinh. I build reliable backends in Ho Chi Minh City.

I'm a fourth-year Software Engineering student at Van Lang University (GPA 3.15/4.0), specializing in backend development with Java, Spring Boot and relational databases. I enjoy designing RESTful APIs, modeling data, and turning a rough idea into a full-stack web application that actually works.

My journey started with plain Servlet, JSP and JDBC, writing everything by hand to understand how the web works underneath a framework. That foundation made Spring Boot click: today I work with Spring Security (JWT, role-based access), Spring Data JPA, Spring AOP and scheduled jobs, on both MySQL and PostgreSQL.

In 2026 I joined the AWS Workforce Bootcamp – First Cloud AI Journey at Amazon Web Services Vietnam. Over 12 weeks I learned cloud fundamentals through guided labs, built a small serverless goods quality monitoring system, and wrote technical blog posts for the AWS Study Group FCJ community. I'm still early in my cloud journey, and Java backend remains my main strength.

Right now I'm building my graduation thesis, a programming learning platform with AI feedback, and looking for a Backend Developer internship where I can work on real-world systems and grow in API design and system architecture.

When I'm not coding, you'll find me swimming, reading comics, or playing Valorant. Before tech took over my schedule, I spent a year as a barista at Highlands Coffee, which taught me a lot about teamwork under pressure.
